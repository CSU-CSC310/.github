# CSC 310 — Software Engineering

This organization hosts repositories that support the teaching and learning of
**CSC 310: Software Engineering** at California Polytechnic State University,
San Luis Obispo.

It provides tools, examples, and reference implementations that help students
engage with software engineering concepts through practical exploration.

## About the Repositories

The collection includes utility tools, small applications, and simple games
that illustrate concepts such as modular design, software architecture,
communication patterns, and the design and evolution of software systems.

These projects provide hands-on experience with software artifacts and continue
to evolve as new teaching needs emerge.

The organization serves as a shared space for experimentation, demonstration,
and **learning by doing**.
